# AI 旅行资料搜集指令

## 我的任务

请帮我研究一个旅行目的地，并将搜集到的资料整理成适合 Obsidian 使用的 Markdown 笔记。

**本次目的地：**【填写国家、地区或城镇】

**研究重点：**【美食 / 特色集市 / 自然景观 / 艺术建筑 / 特色住宿 / 全部】

## 一、搜集要求

1. 优先使用当地政府、旅游局、景点或市场官方页面，以及可靠的文化机构和其他可信来源。
2. 尽可能搜集具有地方特色、值得深入探索的地点，不要只列出最热门的旅游景点。
3. 对餐厅、咖啡馆、集市、自然景点等，尽可能记录名称、地址、特色、适合访问的季节、交通方式及开放时间。
4. 对可能变化的信息，例如营业时间、市场举办日期、票价和预约要求，标明核实日期；无法核实的内容明确标注。
5. 每条重要事实尽可能附上对应的原始来源链接，不要编造网址、地点、评价或数据。
6. 如果资料存在冲突，请指出差异，不要自行猜测。
7. 区分已核实事实、合理推测和个人旅行建议。

## 二、整理要求

请使用清晰的中文，保留当地语言的正式地名，并按以下结构输出：

- 基本信息
- 美食与餐厅
- 特色集市与购物
- 自然景观
- 人文与艺术
- 住宿与体验
- 交通信息
- 实用信息
- 推荐收藏地点
- 资料来源与核实日期

## 三、Obsidian 格式要求

1. 输出完整、可直接复制的 Markdown 正文。
2. 标题清晰，使用列表组织资料。
3. 适当使用 Obsidian 内部链接，例如 `[[法国]]`、`[[普罗旺斯]]`。
4. 不要为尚未核实的地点创建看似真实的资料。
5. 为每个地点保留独立的资料来源。
6. 在笔记末尾列出相关档案和后续需要补充的信息。
7. 不要输出解释过程，只输出整理后的笔记正文及必要的核实说明。

## 四、交付前检查

输出前请检查：

- 是否存在重复地点？
- 是否有无法验证的事实？
- 是否保留原始来源链接？
- 是否标明需要进一步核实的信息？
- 是否符合 Obsidian Markdown 格式？

请先完成资料搜集和来源核查，再生成最终笔记。
